# Лабораторная работа №2. Многопоточное умножение матриц

Многопоточное (многопроцессное) умножение матриц с поддержкой генерации данных через IPC, статического и динамического распределения нагрузки, а также возведения матрицы в степень с барьерной синхронизацией на Python.

---

## Среда выполнения и требования

* **Язык программирования:** Python 3.15+ (используется модуль `multiprocessing` для обхода GIL).
* **Операционная система:** Windows 11 / Linux / macOS (замеры производились на реальной ОС, без виртуальных машин).
* **Сторонние библиотеки:** Не используются (применяются только стандартные модули Python: `multiprocessing`, `time`, `sys`, `random`, `subprocess`, `statistics`).

---

## Структура репозитория

* `script.py` — основной скрипт программы. Реализует:
  * Процесс-генератор матриц и передачу данных через межпроцессное взаимодействие (`mp.Queue`).
  * Умножение матриц в разделяемой памяти (`mp.Array`).
  * Статическое и динамическое распределение строк между процессами.
  * Возведение матрицы в степень ($A^p$) с использованием барьерной синхронизации (`mp.Barrier`) и двойной буферизации[cite: 3].
  * Защиту счетчиков мьютексами и вывод прогресса выполнения[cite: 3].
